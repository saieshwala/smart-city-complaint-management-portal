# MASTER PROMPT — CIVIC COMPLAINT & PUBLIC ISSUE REPORTING PLATFORM

You are a senior software architect, full-stack engineer, ML engineer, DevOps engineer, security engineer, and product designer.

I want you to design and build a production-quality web platform for India that allows citizens to report public infrastructure and civic problems using photographs, location, time, and a simple complaint form.

The core objective is:

> A citizen should be able to photograph a civic problem, upload it, and have the platform identify the problem, determine the appropriate department/authority, generate a professional complaint, submit or route it through the appropriate official channel where technically and legally supported, and allow the citizen to track its status.

Do not build this as merely a CRUD demo. Build it as a scalable civic-tech platform with a clean architecture that can later support multiple Indian cities, municipalities, departments, languages, and government integrations.

In India, citizens frequently encounter problems such as:

* Garbage accumulation

* Illegal dumping
* Drain blockage
* Damaged public infrastructure
* Fallen trees
* Stray/public safety infrastructure issues
* Public toilet problems
* Encroachment-related civic issues

The citizen often does not know:

* Which department is responsible
* Which government portal should be used
* What information must be included
* How to describe the issue professionally
* What location information is required
* Whether the complaint was received
* Whether anyone is working on it

The platform should solve this routing and tracking problem.

# 28. SUBMISSION FLOW

When user clicks Submit:

1. Validate complaint.
2. Validate location.
3. Validate authority.
4. Validate category.
5. Store complaint.
6. Create public complaint ID.
7. Create submission job.
8. Send to integration queue.
9. Worker processes submission.
10. Store response.
11. Update complaint status.
12. Store external reference number.
13. Notify citizen.

Use background jobs.

Do NOT block the user's HTTP request while waiting for an external government system.
